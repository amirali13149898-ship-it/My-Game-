# عکس‌ها

عکس‌ها خام و **بدون عدد** باشن؛ بات همهٔ عددها رو تو کپشن می‌نویسه.
فایل رو با اسم کلید بذار: `main.jpg`، `stats.png`، `race3.jpg` و ...
کلیدها: welcome, help, create, main, stats, abilities, equip, shop, clan, rank, hunt, dungeon, race0..race8
(race0=انسان، 1=الف، 2=دارک الف، 3=دورف، 4=فرشته، 5=ببر، 6=اژدها، 7=گرگ، 8=روباه).

بار اول بات عکس رو آپلود می‌کنه و `file_id` + هش فایل رو تو دیتابیس نگه می‌داره؛ فقط وقتی فایل عوض بشه دوباره آپلود می‌شه.
راه دوم: ادمین عکس رو با کپشن `/setphoto کلید` برای بات بفرسته. `/photos` وضعیت همه رو نشون می‌ده.
کپشن بیشتر از ۱۰۲۴ کاراکتر باشه، اون منو بدون عکس (فقط متن) نشون داده می‌شه.
